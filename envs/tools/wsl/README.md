# tools - 辅助脚本（WSL 版）

|---|---|
| `fetch_all.py` | Windows 侧预取大文件（SGLang 源码、模型权重、Mooncake trace）到 `D:\first-task\work\`，供 WSL 离线使用 |
| `make_shot.py` | 将终端文本（`evidence/*.txt`）渲染为深色终端风格 PNG 截图（`evidence/*.png`），Chrome headless + 精确尺寸计算 |
| `make_ops_pdf.py` | 生成 WSL 版操作说明 PDF（已由 `HW1/deliverables/操作说明.pdf` 替代，保留脚本供追溯） |
